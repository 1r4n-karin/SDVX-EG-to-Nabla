# SOUND VOLTEX コナステ版 VF計算ツール 使用者マニュアル

本アプリケーションは、SOUND VOLTEX（以下SDVX）のコナステ版のスコアを手動で記録し、最新のアーケード版（Valkyrie model以降）の計算基準に合わせた総合VOLFORCE（以下VF）を算出・管理するためのツールです。
---

## 1. 画面の基本構成と表示の見方

### ① 総合VF（画面右上）
* 登録されたすべてのスコアの中から、**算出された単曲VFが高い上位50譜面（ベスト枠）**が自動的に抽出され、その合計値が表示されます。
* アーケード版の仕様に準拠し、合計値を1,000で割った数値（例：`18.234` のような小数点以下3桁の形式）でリアルタイムに計算・表示されます。

### ② VF 対象曲ベスト 50（画面下部）
* 現在の「総合VF」の根拠となっている上位50譜面が、単曲VFの高い順に1位から50位まで一覧表で表示されます。
* 各行の右端には「削除」ボタンがあり、間違えて登録したスコアをその場で即座に消去できます。

---

## 2. データの登録手順

データ入力は、対象となる難易度に応じて2つのモードを切り替えて行います。

### モード1：マスタから選ぶ (Lv18以上の楽曲)
1. 入力モードのラジオボタンで「**マスタから選ぶ (Lv18以上)**」を選択します。
2. 「**楽曲を検索 (キーワード入力)**」の欄に、登録したい曲名の一部を入力します。
3. 「**難易度で絞り込み**」ドロップダウンを併用することで、Lv18帯・Lv19帯・Lv20のみに絞り込むことも可能です。
4. 「**楽曲を選択**」から目的の譜面を選びます。
5. 「**スコア**」欄に1,000万点満点の数値を半角数字で入力します（例：`9924512`）。
6. 「**クリアメダル**」を選択し、「**スコアを保存**」をクリックします。

### モード2：難易度を直接指定 (Lv17以下の楽曲)
1. 入力モードのラジオボタンで「**難易度を直接指定 (Lv17以下など)**」を選択します。
2. 「**曲名 (自由入力・省略可)**」欄に曲名を入力します。
   * ※空欄のまま保存した場合は、自動的に「`[直接入力] Lv 17.5`」といった名前で登録されます。
3. 「**難易度（レベル定数）を直接指定**」のドロップダウンから、対象のレベル（17.5〜10.0）を選択します。
4. あとはモード1と同様に「スコア」と「クリアメダル」を入力し、「**スコアを保存**」をクリックします。

---

## 3. データのバックアップと復元

登録したスコアデータは、インターネット上のサーバーではなく、お使いのブラウザ内部の記憶領域（LocalStorage）に自動保存されています。そのため、ページを閉じたりPCを再起動したりしてもデータは保持されます。

しかし、**ブラウザの閲覧履歴（キャッシュやクッキー）を削除すると、記録したスコアデータがすべて消去されてしまいます。** 万が一に備え、定期的なバックアップを強く推奨します。

### データのバックアップ（エクスポート）
1. 「スコアデータのバックアップ・復元」エリアにある「**自分のスコアをCSVとしてエクスポート (PCに保存)**」ボタンをクリックします。
2. `sdvx_konaste_scores.csv` というファイルがパソコンにダウンロードされます。このファイルを大切に保管してください。

### データの復元（インポート）
1. 万が一データが消えてしまった場合、「**過去のスコアCSVからインポート (復元)**」の「ファイルを選択」ボタンをクリックします。
2. 保管しておいたバックアップファイル（`sdvx_konaste_scores.csv`）を選択します。
3. 「スコアデータをインポートしました！」と表示され、過去の全記録と総合VFが一瞬で元通りに復元されます。

## 4. トラブルシューティング

### 画面を開いたが「楽曲マスタを読み込めませんでした」と表示される / 選択肢が出ない
* **原因**: GitHub Pages側の更新（デプロイ）がまだ完了していないか、ブラウザが古いページの状態をキャッシュとして記憶している可能性があります。
* **対処法（スーパーリロード）**: 
  アプリを開いた状態で以下のキーボードを押して、キャッシュを強制消去してください。
  * **Windows**: `Ctrl` + `F5`
  * **Mac**: `Cmd` + `Shift` + `R`
